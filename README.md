# 🕹️ Projet de Contrôle Distant – GUI + Serveur

Ce projet te permet de **contrôler à distance un PC** sur le même réseau via une interface graphique Python.  
Tu peux :

- 🎵 Lancer des sons
- 💬 Faire parler la machine
- 📩 Afficher des popups
- 🖱 Bouger la souris
- 🛠 Ouvrir une page HTML
- 🌀 Afficher des "Emolio"

---

## ⚙️ Installation

### 1. ⚡ Prérequis

- Python 3.8+ installé (64 bits recommandé)
- Système d’exploitation : **Windows**
- Les deux machines doivent être sur le **même réseau local**

### 2. 📦 Installation des dépendances

Dans le terminal, dans le dossier du projet :

```bash
pip install -r requirements.txt
```
